# 文章编辑与新建功能实现计划

## 1. 创建页面文件
- 创建 `src/app/admin/articles/new/page.tsx` - 新建文章页面
- 创建 `src/app/admin/articles/edit/[id]/page.tsx` - 编辑文章页面

## 2. 页面布局设计
- 复用文章管理页的侧边栏导航、主内容区和页脚结构
- 采用响应式设计，适配不同屏幕尺寸

## 3. 表单实现
- 标题输入框（必填，最大255字符）
- 分类输入框（可选，最大128字符）
- 描述输入框（可选，多行文本）
- Vditor Markdown编辑器（必填，用于文章内容）
- 提交按钮

## 4. 功能实现
### 新建文章
1. 创建表单组件，包含所有必要字段
2. 集成Vditor编辑器
3. 实现表单提交逻辑，调用Prisma Client创建新文章
4. 成功后跳转到文章管理页

### 编辑文章
1. 使用Next.js动态路由获取文章ID
2. 服务器端获取文章数据
3. 表单预填充文章数据
4. 实现表单提交逻辑，调用Prisma Client更新文章
5. 成功后跳转到文章管理页

## 5. 技术栈
- Next.js 16（最新版本）
- TypeScript
- Tailwind CSS
- Vditor Markdown编辑器
- Prisma Client

## 6. 代码规范
- 遵循现有项目的代码风格
- 使用TypeScript类型安全
- 组件化设计
- 错误处理
- 表单验证

## 7. 实现步骤
1. 创建页面文件结构
2. 实现页面布局和导航
3. 集成Vditor编辑器
4. 实现表单组件和验证
5. 实现新建文章功能
6. 实现编辑文章功能
