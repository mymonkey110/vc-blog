# 实现计划

## 1. 创建新的 Menu 组件
- **文件位置**: `src/components/Menu.tsx`
- **设计基准**: 基于文章管理页 (`src/app/admin/articles/page.tsx`) 的菜单样式
- **功能**: 仅包含仪表盘和文章管理两个菜单选项
- **样式**: 使用 Tailwind CSS，保持与现有设计一致
- **活跃状态**: 根据当前路径自动高亮对应的菜单选项

## 2. 更新 Admin Layout
- **文件位置**: `src/app/admin/layout.tsx`
- **修改内容**: 添加侧边栏布局，集成新的 Menu 组件
- **布局结构**: 采用 `flex` 布局，左侧为侧边栏，右侧为内容区域
- **响应式设计**: 在小屏幕上隐藏侧边栏

## 3. 实现登出功能
- **文件位置**: `src/app/admin/logout/route.ts`
- **功能**: 清除 `admin_token` cookie 并跳转到登录页
- **在 Menu 组件中添加登出链接**: 指向 `/admin/logout` 路由

## 4. 更新文章管理页
- **文件位置**: `src/app/admin/articles/page.tsx`
- **修改内容**: 移除重复的侧边栏代码，使用新的布局结构

## 5. 验证实现
- 确保仪表盘和文章管理页都使用新的 Menu 组件
- 测试菜单的活跃状态显示正确
- 测试登出功能正常工作

## 技术要点
- 使用 Next.js App Router 的布局系统
- 使用 `usePathname` 钩子检测当前路径
- 使用 Tailwind CSS 实现响应式设计
- 使用 Next.js 的 `cookies` API 处理登出逻辑
