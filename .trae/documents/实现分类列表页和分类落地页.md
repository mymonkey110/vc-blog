# 实现分类列表页和分类落地页

## 1. 项目结构和现有组件分析

* 导航栏（NavigationBar）和页脚（Footer）组件已存在，可直接复用

* 项目使用 Next.js 16，采用 App Router

* 使用 Prisma 作为 ORM，连接 PostgreSQL 数据库

* 文章模型（Article）包含 category 字段，类型为 String?

## 2. 分类页UI设计

### 分类列表页

* 显示所有分类，每个分类显示文章数量

* 点击分类跳转到分类落地页

* 采用卡片式布局，悬停效果

### 分类落地页

* 显示该分类下的所有文章

* 按年份分组显示

* 每个年份下的文章按时间倒序排列

* 采用时间线式布局

## 3. 实现方案

### 分类列表页（/categories）

* 使用 SSG（静态生成）模式

* 从数据库中查询所有不同的分类，并统计每个分类下的文章数量

* 按照UI设计渲染分类列表

### 分类落地页（/categories/\[name]）

* 使用 SSG（静态生成）模式

* 从数据库中查询该分类下的所有文章，按年份分组

* 按照UI设计渲染文章列表，按年份分组显示

## 4. 数据库查询

* 分类列表页：使用 Prisma 的 groupBy 和 count 功能，查询所有非空分类及其文章数量

* 分类落地页：使用 Prisma 的 findMany 功能，按分类过滤，按 createdAt 倒序排序，然后在代码中按年份分组

## 5. 路由结构

* 在 src/app 目录下创建 categories 目录

* 在 categories 目录下创建 page.tsx（分类列表页）

* 在 categories 目录下创建 \[name] 目录，其中创建 page.tsx（分类落地页）

## 6. 实现步骤

1. 创建分类列表页（/categories/page.tsx）
2. 创建分类落地页（/categories/\[name]/page.tsx）
3. 实现数据库查询逻辑
4. 按照UI设计渲染页面
5. 测试页面功能
