## 实现步骤

1. **修改数据库模型**
   - 在 `prisma/schema.prisma` 中为 Article 模型添加 `status` 字段，类型为 `String`，默认值为 `"publish"`
   - 确保 status 字段仅允许 "draft" 和 "publish" 两个值

2. **运行数据库迁移**
   - 执行 `npx prisma migrate dev` 生成迁移文件
   - 运行迁移将 status 字段添加到数据库
   - 确保已存在的数据默认设置为 "publish"

3. **创建 Server Action**
   - 在 `src/app/admin/articles` 目录下创建 `actions.ts` 文件
   - 实现获取文章列表的 Server Action
   - 实现获取单篇文章的 Server Action
   - 实现更新文章的 Server Action
   - 实现创建文章的 Server Action

4. **修改后台文章管理页面**
   - 将 `src/app/admin/articles/page.tsx` 中的 mock 数据替换为使用 Server Action 获取真实数据
   - 添加文章状态显示和筛选功能
   - 确保文章列表能正确显示所有文章

5. **完善编辑页面逻辑**
   - 确保 `src/app/admin/articles/edit/[id]/page.tsx` 使用 Server Action 通过 id 获取文章内容
   - 添加文章状态切换功能
   - 确保编辑后的数据能正确保存到数据库

6. **测试功能完整性**
   - 测试文章列表页能正确显示所有文章
   - 测试编辑页面能正确获取和更新文章
   - 测试文章状态切换功能
   - 测试新建文章功能

## 技术要点

1. **Server Action**：使用 Next.js 的 Server Action 功能替代 RESTful API
2. **数据库迁移**：使用 Prisma 进行数据库迁移，确保数据一致性
3. **状态管理**：在前端使用 React hooks 管理状态
4. **类型安全**：确保 TypeScript 类型定义与数据库模型一致
5. **用户体验**：添加加载状态和错误处理
